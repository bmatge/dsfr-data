Comment utiliser le Pipeline
  1. Ajouter des composants avec le menu « Ajouter une étape » de la barre d'actions.
  2. Connecter : glissez d'un cercle de sortie (droite) vers un cercle d'entree (gauche).
  3. Configurer : remplissez les champs dans chaque noeud.
  4. Exécuter : cliquez "Exécuter" pour voir les données traverser le pipeline.
  5. Inspecter : cliquez sur un noeud pour voir ses données dans le panneau de droite.
Pipeline type : Source (fetch) → Requêter (transforme) → Sortie (affiche).
