4 Apparence

Couleurs par catégorie

Fixe la couleur d’une série ou d’une catégorie, quel que soit son rang. Les autres gardent la palette.

Axes et repères (bornes, lignes de référence, cibles)

Les bornes sont arrondies à la graduation voisine.

Lignes de référence

Un trait pointillé sur un seuil (une valeur) ou sur une étiquette (une date, une catégorie)

Cibles

Un objectif à une échéance, relié au dernier point connu par une trajectoire en pointillés

Mode de génération

Embarqué : les données sont copiées dans le code (simple, mais figé). Dynamique : elles sont rechargées depuis l’API à chaque affichage.

Ce document Grist n'est pas public. Le code généré ne fonctionnera que si le document est rendu public dans Grist.

Nettoyage des données

Prépare les données brutes avant traitement : espaces, textes « 123 » en nombres, renommage de colonnes.

Cadre officiel DSFR

Encadre le graphique dans le bloc officiel DSFR : titre, source, date, téléchargement, plein écran.
