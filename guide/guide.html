Guide de ChartsBuilder

ChartsBuilder permet à tout agent public de transformer une donnée ouverte en graphique dynamique, accessible et conforme au Système de design de l'État. Ce guide présente ses outils et la bibliothèque libre dsfr-data sur laquelle il repose.

Chaque outil propose une visite guidée, lancée une seule fois automatiquement ; vous pouvez la relancer ou la réinitialiser ici.

L'interface

L'application est accessible depuis la page d'accueil qui regroupe tous les outils :

  • Sources : connecter et gérer les sources de données (API, data.gouv.fr, Grist, INSEE, jeux locaux)
  • Créer un graphique : le Builder, un générateur visuel de graphiques pas à pas
  • Studio IA : graphiques et tableaux de bord composés par conversation avec l'IA Albert
  • Créer une carte : points, zones et fiches au clic, sur des données géographiques
  • Créer un tableau de bord : assembler ses graphiques favoris sur une grille
  • Playground : éditeur de code interactif avec aperçu en temps réel
  • Suivi : suivi des déploiements de widgets en production

Télémétrie opt-in (dsfr-data-beacon)

La bibliothèque n'envoie aucune télémétrie par défaut. Pour alimenter le tableau de bord de monitoring d'une instance auto-hébergée, déposez un <dsfr-data-beacon> dans la page : la présence d'une url vaut opt-in, et un simple réglage global sert de coupe-circuit. 

<!-- Opt-in : déclare la cible de collecte de CETTE page -->
<dsfr-data-beacon url="https://mon-instance.example.fr/api/beacon"></dsfr-data-beacon>

<!-- Coupe-circuit global : désactive toute télémétrie, même si un beacon est présent -->
<script>window.DSFR_DATA_BEACON = false;</script>
