0. Découvrir ChartsBuilder

Présentation3 min 44

Ce que ChartsBuilder change pour publier des données : le problème des images figées, la bibliothèque dsfr-data, l'application et le tour de ses outils.

[À l'écran] Carton titre : sur-titre « Présentation », « Découvrir ChartsBuilder ».

Voix off : Un graphique vivant, accessible et à la charte de l'État, dans la page de votre site : c'est ce que ChartsBuilder fait d'une donnée ouverte. Trois minutes pour le découvrir.

Le problème : des images figées (00:12)

[À l'écran] Page « Industrie du futur » d'un site d'exemple au Système de design de l'État : titre, chapeau, puis l'image d'un graphique copié d'un rapport (« Graphique 3 : Nombre de bénéficiaires par région », barres bleues d'outil bureautique, légende « Série1 », source « données provisoires au 31/12/2021 ») ; zoom sur l'image, le pointeur désigne la date, puis la légende.

Voix off : Les sites publics illustrent encore souvent leurs données par une image : un graphique copié d'un rapport, ou fait avec un outil bureautique. Cette image n'est pas à jour, elle ne respecte pas la charte de l'État, et elle n'est pas accessible. Pourtant, l'information est sans doute disponible en open data, ou dans un tableur Grist.

L'accueil : une bibliothèque, une application (00:32)

[À l'écran] Accueil de ChartsBuilder : titre « Créez des visualisations conformes au Design System de l'État. », les trois étapes « 01 · Connecter », « 02 · Configurer », « 03 · Exporter » encadrées, un carrousel de graphiques à droite, les boutons « Créer un graphique » et « Démarrer avec l'IA » ; défilement jusqu'à la grille « Tous les outils » ; survol des tuiles Sources, Studio IA, Créer un graphique, Créer une carte, Créer un tableau de bord, Playground.

Voix off : ChartsBuilder a été conçu pour publier des graphiques dynamiques en HTML, connectés à des données ouvertes, et conformes au Système de design de l'État. Son accueil le résume en trois étapes : connecter, configurer, exporter. Pour y arriver, deux outils : une bibliothèque libre, dsfr-data, pour les intégrateurs ; et par-dessus, une application guidée, pour tous les autres.

Sources (00:56)

[À l'écran] Clic sur « Sources » : écran avec une connexion (« Prix des contrôles techniques ») et les jeux de données enregistrés. Clic sur « Nouvelle connexion », adresse du jeu « Industrie du futur » collée, « Continuer », message « Plateforme détectée : OpenDataSoft. Tout est prêt — enregistrez pour récupérer les données. » ; nom « Industrie du futur » saisi, « Enregistrer » : la connexion apparaît dans la liste.

Voix off : Tout part des données. J'ouvre Sources : l'outil reconnaît les portails de l'administration, data.gouv.fr, OpenDataSoft, Grist, INSEE Melodi, ou toute API. Je colle l'adresse d'un jeu de données : la plateforme est détectée aussitôt. Je nomme la connexion, j'enregistre : elle rejoint la liste, prête à servir.

Créer un graphique (01:18)

Panneau gauche en quatre étapes numérotées (« Source de données » avec « Industrie du futur » sélectionnée, « Type de graphique », « Configuration des données », « Apparence ») ; étiquettes nom_region, valeur nombre_beneficiaires ; clic sur « Générer » : histogramme dans l'onglet « Aperçu » ; onglet « Code » ; « Plus d'actions », « Assistant » : volet de l'assistant, question « Changer les couleurs » saisie et envoyée, le réglage « Palette » est encadré ; fermeture du volet.

Le graphique s'affiche tel qu'il sera dans la page ; l'onglet Code contient le bloc HTML à coller dans son site. Un doute sur un réglage ? L'assistant, dans Plus d'actions, le montre : je tape Changer les couleurs, il encadre Palette.

Studio IA (01:48)

[À l'écran] Clic sur « Studio IA » : à gauche la source « Industrie du futur » chargée et la conversation (« Bienvenue dans le Studio IA… »), à droite la page à composer. Saisie de « les bénéficiaires par région, en barres », « Envoyer » ; les appels d'outils défilent dans le fil ; l'histogramme par région apparaît dans l'aperçu.

Voix off : Le Studio IA, lui, prend la demande en français. Ma source est chargée ; j'écris : les bénéficiaires par région, en barres. J'envoie. Voix off : Le Playground dévoile l'envers du décor : trois balises, source, requête, graphique. Quel que soit l’outil, on repart avec le même bloc de code, à coller dans sa page.

Au-delà de l'application (03:27)

[À l'écran] Plan fixe : logo ChartsBuilder, « dsfr-data, licence MIT · serveur MCP · hébergeable ».

Voix off : Un serveur MCP, le protocole qui relie les assistants IA à des outils, apprend la bibliothèque à tout assistant. Et l'ensemble est libre, sous licence MIT : chaque administration peut l'héberger. Vos données méritent mieux qu'une image.
